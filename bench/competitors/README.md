# Competitor packs

Verbatim copies of third-party instruction packs, run as benchmark arms for
head-to-head comparison (`compressor benchmark --competitor <name>`). Each is
delivered through the same output-style (system-prompt) channel compressor
uses, `keep-coding-instructions: true`, with no compression hook — these tools
are output-shaping only.

comparison only; their licenses and authorship are the upstream projects'.
